# Обновление нескольких уровней и новые шаблоны документов

Пользователь попросил общие исправления для новых и повторно разобранных программ. Публикация GitHub Pages приостановлена по его указанию.

- Удалить пустые дубликаты «Знать / Уметь / Владеть», сохранить содержательные результаты.
- Заменить подтверждённые шрифтовые маркеры списков; сохранить группы и вложенные пункты педагогической практики.
- Поддержать учебные планы СПО и аспирантуры, недельный график групп СПО и многобуквенные обозначения аспирантуры. Сомнительные значения отмечать, не придумывать.
- Поддержать паспорт и таблицы практик СПО, точную квалификацию и срок обучения ООП. Различать профессиональные модули.
- Одна шапка обновления, карточки уровней с несколькими программами, один запуск и общий ход работы. Убрать пользовательский принудительный разбор.
- Проверять источники перед разбором. Если изменился документ, повторно разобрать ОП; при неизменных документах и актуальной версии разбора использовать сохранённые результаты. Ненадёжные HTTP-метаданные не заменяют проверку хеша.
- Регрессии на реальных источниках и демонстрационном сайте, резервная копия БД, обновление локальных результатов с историей версий, проверка браузером, перезапуск Docker.
