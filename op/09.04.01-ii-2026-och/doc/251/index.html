Темы и содержание

  1. Введение в обработку естественного языка. Сервисы и библиотеки для обработки естественного языка Основы предварительной обработки текста. Обзор прикладных задач. Обзор сервисов и библиотек для обработки естественного языка. Обзор архитектур для решения задач обработки естественного языка. Инструментарий Keras, TensorFlow и PyTorch для построения моделей нейронной сети для обработки естественного языка
  2. Нейронные сети для обработки текстовых данных Предварительная обработка текстовых данных: векторизация текста. Способы векторизации: слова, символы, N-граммы. Прямое кодирование токенов. Векторное представление токенов. Токенизация. Частотный подход для цифрового представления текста: метод «Мешок слов». Методы One Hot Encoding (OHE), TF-IDF. Семантическое моделирование текстов. Алгоритмы PLSA, LDA. Дистрибутивная семантика. Слой Embedding. Использование предварительно обученных векторных представлений слов. Алгоритмы Word2vec, fasttext, GloVe. Построение моделей инструментами Keras и TensorFlow для анализа эмоциональной окраски отзывов в наборе данных IMDB
  3. Одномерные сверточные сети для обработки последовательностей Применение операции свертки для текстовых последовательностей. Построение модели одномерной сверточной нейронной сети при помощи инструментов TensorFlow для анализа эмоциональной окраски отзывов в наборе данных IMDB
  4. Рекуррентные нейронные сети Принцип построения рекуррентных сетей. Практическое приложение рекуррентных сетей. Виды рекуррентных сетей. RNN. Реализация сети RNN на основе Numpy. LSTM. GRU. Инструменты Keras и TensorFlow для построения рекуррентных нейронных сетей
  5. Прогнозирование временных рядов Обработка временных последовательностей. Рекуррентное прореживание. Наложение рекуррентных слоев. Двунаправленные рекуррентные нейронные сети. Изучение принципов работы с числовыми временными рядами на примере анализа временных последовательностей о погоде
  6. Сверточные и рекуррентные сети для обработки длинных последовательностей Обучение и оценка простой одномерной сверточной сети на данных по прогнозированию температуры из набора Jena. Стратегия объединения одномерной сверточной и рекуррентной сетей для обработки длинных последовательностей
