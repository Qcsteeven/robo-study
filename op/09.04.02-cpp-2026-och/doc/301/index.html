Нейронные сети и их практическое применение

Темы и содержание

  1. Основы нейронных сетей и архитектуры Введение в нейронные сети: перцептрон, полносвязные сети, функции активации, обучение. Основные архитектуры: CNN для изображений, RNN/LSTM для последовательностей, трансформеры. Выбор архитектуры под задачу
  2. Методологии тестирования ML-систем Виды тестирования нейросетевых систем: unit-тесты, интеграционное, валидационное, A/B-тестирование. Метрики оценки качества (Accuracy, Precision, Recall, F1, ROC-AUC). Тест-кейсы и тестовые сценарии. Автоматизация тестирования
  3. Развертывание и настройка нейросетевых систем Контейнеризация моделей (Docker). Оркестрация (Kubernetes). Оптимизация моделей: TensorRT, ONNX, OpenVINO. Развертывание в облаке и на Edge-устройствах. Настройка производительности и мониторинг
  4. MLOps и практика внедрения нейросетевых систем Жизненный цикл ML-систем: разработка → тестирование → развертывание → мониторинг. CI/CD для ML. Версионирование данных и моделей. Обнаружение дрифта данных. Кейсы внедрения в промышленности

Формируемые компетенции

  • ПК-1 — Способен вести разработку и проектирование информационных систем по требования заказчика, в том числе разрабатывать функциональные прототипы информационных систем
  • ПК-4 — Способен разрабатывать планы и контролировать работы по управлению ИТ-проектами по созданию информационных систем

Результаты обучения

  • Знать Архитектуры нейронных сетей для промышленных задач (CNN, RNN, трансформеры) Методологии тестирования ML-систем (unit-тесты, интеграционное, A/B-тестирование) Инструменты для развертывания и контейнеризации ML-моделей (Docker, Kubernetes) Способы настройки и оптимизации нейросетей для промышленной эксплуатации (TensorRT, ONNX) Метрики оценки качества и мониторинга моделей в продакшене
  • Уметь Разрабатывать и выполнять тестовые сценарии для нейросетевых прототипов Развертывать ML-модели в облачных и on-premise средах Настраивать конвейеры обработки данных и инференса Проводить нагрузочное тестирование и анализ производительности
  • Владеть Инструментами тестирования ML-систем (pytest, unittest, MLflow) Средствами контейнеризации и оркестрации (Docker, Kubernetes) Библиотеками для работы с нейросетями (PyTorch, TensorFlow) Практиками MLOps: CI/CD для ML, мониторинг, версионирование моделей Фреймворками для развертывания (FastAPI, Flask, Triton Inference Server)
